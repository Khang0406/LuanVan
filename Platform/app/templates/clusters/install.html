Khuyến nghị: Bootstrap sudo NOPASSWD trước khi install
Playbook cần quyền sudo để cài package, tắt swap, cấu hình sysctl và cài K3s. Nếu đã bấm Bootstrap sudo NOPASSWD thành công ở Server Inventory, ô sudo password có thể để trống khi install Kubernetes.
Trường sudo password chỉ còn là phương án dự phòng cho lần install trực tiếp khi node chưa bootstrap. Luồng khuyến nghị: Test SSH → Test Ansible → Bootstrap sudo NOPASSWD → Install Kubernetes.

Checklist

  • SSH từ máy web đến tất cả node
  • Ansible ping thành công tới tất cả node
  • User SSH có quyền sudo trên từng node
  • Bootstrap sudo NOPASSWD thành công để install không cần nhập password nhiều lần
  • Node truy cập internet hoặc mirror nội bộ
  • Port 6443/10250 mở trong LAN

Luồng thực hiện

  1. Chọn master/worker.
  2. Bấm Dry-run inventory để xem trước file Ansible inventory.
  3. Nếu chưa bootstrap sudo, quay lại Server Inventory và bấm Bootstrap sudo NOPASSWD.
  4. Nếu inventory đúng, bấm Install Kubernetes.
  5. Sau khi cài xong, kiểm tra node và deploy website demo.
