# Use cases

## Admin/DevOps

- Đăng nhập hệ thống.
- Thêm/sửa/xem server.
- Kiểm tra SSH bằng Ansible ping.
- Tạo cluster và chọn master/worker.
- Chạy Ansible playbook cài K3s/Kubernetes.
- Xem log cài đặt.
- Xem trạng thái node trong cluster.
- Xem audit log.

## Developer

- Đăng nhập hệ thống.
- Tạo application.
- Tạo service từ Docker image.
- Deploy service lên Kubernetes.
- Xem pod status.
- Xem logs.
- Scale replicas.
- Redeploy khi image thay đổi.
