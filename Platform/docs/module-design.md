# Module design

- Auth/RBAC: đăng nhập và phân quyền demo.
- Server Inventory: quản lý máy chủ target.
- Ansible Automation: sinh inventory, chạy playbook, lưu log job.
- Cluster Management: tạo cluster, chọn master/worker, refresh node status.
- Application Management: tạo application/namespace.
- Deployment Management: tạo service từ image, render manifest, deploy/scale/logs.
- Audit Log: ghi nhận thao tác quan trọng.
