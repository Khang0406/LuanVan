# Module design

Bản hiện tại chỉ triển khai UI prototype. Các module backend được tạo thư mục/file trống để sau này bổ sung.

## UI hiện có

- Dashboard tổng quan.
- Server Inventory.
- Kubernetes Setup Wizard.
- Cluster Detail.
- Applications.
- Service/Deployment forms.
- CI/CD Flow.
- Monitoring.
- Job Logs.
- Audit Log.

## Module backend sẽ bổ sung sau

- Auth/RBAC.
- Server Inventory Service.
- Ansible Automation Service.
- Cluster Management Service.
- Application Management Service.
- Deployment Management Service.
- Monitoring/Logging Service.
- Audit Service.
